# NANE — من يعرف العائلة أكثر؟

لعبة اجتماعية عائلية عربية، يتنافس فيها 3 أو 4 لاعبين بشكل فردي عبر معرفة أفراد العائلة، الرسائل المجهولة، الأسئلة السرية، وتخمين أصحاب الإجابات.

> الهدف: لعبة اجتماعية ذكية وممتعة، يتغير محتواها من مباراة إلى أخرى، وتستهدف مباراة مدتها 60–75 دقيقة.

## حالة المشروع

نحن في **المرحلة الأولى: تثبيت المنتج وبناء أساس التشغيل النظيف**.

تم اعتماد مستودع جديد حتى لا تختلط اللعبة الجديدة بمنطق CHAOS FAMILY BATTLE القديم. سنعيد استخدام البنية المجربة اللازمة فقط: خادم Python محلي، SQLite، الغرف والمقاعد والجلسات، نفق Cloudflare Quick Tunnel، وواجهة اختبار الاتصال. لن ننقل محرك العملات أو التحديات أو أحداث الفوضى أو واجهة المباراة القديمة.

## المتطلبات المثبتة

- 3 أو 4 لاعبين حقيقيين، بلا لاعب وهمي.
- منافسة فردية؛ لكل لاعب نقاطه وترتيبه.
- ملف شخصية لا يقل عن 21 إجابة مكتملة لكل لاعب.
- خمس مراحل لعب متنوعة، ومدة مستهدفة 60–75 دقيقة.
- أسئلة تبدأ سهلة ثم تتدرج إلى متوسطة وصعبة وفق أداء المجموعة والمعلومات التي لم تُكشف.
- رسائل مجهولة تُبنى من حقائق اللاعبين، مع تلميحات متدرجة.
- اللاعب يختار سؤالًا من بنك منظم؛ يوجهه النظام سرًا إلى مجيب عشوائي مناسب من بقية اللاعبين، ثم يخمن الآخرون إجابته.
- أسئلة جديدة يجيب عنها الجميع سرًا، ثم يخمن الجميع صاحب كل إجابة.
- الإجابات والاختيارات الخاصة لا تُرسل إلى متصفحات الآخرين قبل الكشف الجماعي.
- واجهة عربية RTL تعمل على الشاشات الصغيرة، مع JavaScript محافظ وXMLHttpRequest لدعم Safari القديم قدر الإمكان.
- الخادم المحلي على Linux Mint هو مصدر الحقيقة، والهواتف تتصل به عبر نفس رابط HTTPS المؤقت.

## التقنية التشغيلية

- Python 3 standard library فقط في الأساس.
- SQLite واحدة على اللابتوب، خارج المستودع.
- الخادم يربط على `127.0.0.1` فقط.
- Cloudflare Quick Tunnel يوفر رابط HTTPS مؤقتًا؛ لا حاجة إلى port forwarding أو hotspot.
- كل اللاعبين يفتحون الرابط المؤقت نفسه.
- لا نعدل إعدادات VPN أو Kill Switch أو الجدار الناري.

## التشغيل

بعد اكتمال ملفات المرحلة الأولى:

```bash
git pull --ff-only
bash run_tests.sh
bash start_nane.sh
```

يتطلب تشغيل الاتصال الخارجي وجود `cloudflared` على Linux Mint. سيعرض السكربت رابطًا مؤقتًا؛ افتح الرابط نفسه على اللابتوب والهواتف. أبقِ نافذة الطرفية مفتوحة أثناء اللعب، وأوقف الجلسة عبر Ctrl+C.

## المراحل الخمس

1. **المرحلة الأولى — المنتج والأساس النظيف:** تثبيت القواعد، ترحيل البنية التشغيلية القابلة لإعادة الاستخدام، إعداد الغرف والجلسات والاختبارات الأولية.
2. **المرحلة الثانية — مكتبة المحتوى والذكاء:** بنك كبير للأسئلة، تصنيف المجالات والصعوبة، قوالب الرسائل، اختيار موزون، توازن الأدوار ومنع التكرار.
3. **المرحلة الثالثة — محرك المباراة والخادم:** ملف الشخصية، حالات المراحل، الإجابات الخاصة، التوجيه السري، التوقيت والنقاط والاستعادة.
4. **المرحلة الرابعة — الواجهة الاحترافية:** تجربة عربية RTL كاملة للغرف والملف الشخصي والمراحل الخمس والرسائل والكشف والنتائج.
5. **المرحلة الخامسة — الاختبار والإطلاق:** اختبارات وحدات وHTTP وتكامل وأمان، اختبار 3 و4 لاعبين، ثم اختبار فعلي على Android وiPhone 4S / Safari 9.3.6.

## حدود ما هو منجز الآن

الأساس المنقول هو بنية تشغيل وغرف واتصال فقط، وليس اللعبة النهائية. نجاح الاختبارات الآلية لا يثبت توافق كل جهاز فعليًا. سنسجل نتائج الاختبار على اللابتوب والهواتف بشكل منفصل وصريح.

## الخصوصية والأمان

- لا تحفظ قواعد البيانات أو رموز الجلسات أو رموز الغرف أو روابط Tunnel أو سجلات التشغيل في Git.
- Quick Tunnel رابط عام مؤقت؛ رمز الغرفة والجلسات هي طبقات التطبيق، وليست عشوائية عنوان الرابط وسيلة حماية.
- صفحة `/compatibility` تشخيصية فقط وبلا بيانات خاصة؛ تزال أو تعطل قبل أي نشر عام.
- لا يعتمد النظام على خدمات ذكاء اصطناعي خارجية أو APIs مدفوعة في الإصدار الأول. ذكاء اللعبة يبدأ بمحرك حتمي قابل للاختبار ومكتبة محتوى منظمة.
