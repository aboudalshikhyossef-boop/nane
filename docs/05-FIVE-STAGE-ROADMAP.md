# خطة بناء NANE — خمس مراحل تنفيذية

## 1. المنتج والأساس النظيف — مكتملة برمجيًا
- تثبيت قواعد اللعبة الفردية لخ 3–4 لاعبين.
- 21 سؤال ملف شخصي على الأقل.
- تعريف الفصول الخمسة والنقاط والصعوبة والسرية.
- نقل مخزن الغرف والجلسات من المشروع السابق مع تغيير الهوية وقاعدة البيانات.
- خادم HTTP نظيف لا يستورد محرك اللعبة القديمة.
- سكربت تشغيل Linux Mint + Cloudflare Quick Tunnel.
- واجهة Lobby جديدة وأداة تشخيص.
- اختبارات store وHTTP والواجهة وCI.

**بوابة الخروج:** الاختبارات الآلية ناجحة، ومسارات الغرفة والجلسات تعمل على الخادم الجديد، والوثائق والخصوصية واضحة.

## 2. مكتبة المحتوى والذكاء — مكتملة برمجيًا
- 150 سؤالًا منسقًا على الأقل كبداية و40 قالب رسالة.
- تصنيف حسب المجال والنوع والصعوبة.
- محرك اختيار موزون ومنع تكرار.
- مصفوفة معرفة زوجية وتوازن الاستهداف.
- رسائل سياقية ذات تلميحات متدرجة.
- اختبارات المحتوى والعدالة والتدرج والتكرار.

**بوابة الخروج:** كل عنصر له جواب صالح؛ لا تلميحات متناقضة؛ الاختيار قابل لإعادة الإنتاج.

## 3. محرك المباراة والخادم — مكتملة برمجيًا
- إنشاء ملف شخصية بقيد 21 إجابة مكتملة على الأقل.
- تحديث الملف قبل المباراة وقفل التعديل أثناءها.
- إدارة الفصول الخمسة والتوقيت والاستئناف.
- تخزين الإجابات السرية والتخمينات على الخادم فقط.
- التوجيه السري لسؤال اللاعب إلى مجيب مؤهل.
- احتساب النقاط والترتيب.
- منع معالجة الطلب مرتين، واستعادة المرحلة بعد refresh/reconnect.

**المخرجات المنجزة:** ملفات شخصية مقيّدة بـ21 إجابة، خمس مراحل، 30 مهمة لثلاثة لاعبين و39 لأربعة، استجابات سرية، نقاط، مهل، حفظ واستعادة، منع الأفعال القديمة برقم تسلسلي.

**بوابة الخروج:** اجتازت اختبارات المحرك وHTTP والخصوصية والاستعادة، مع تشغيل مباراة كاملة لثلاثة وأربعة لاعبين. راجع `docs/06-MATCH-ENGINE.md`.

## 4. الواجهة الاحترافية — مكتملة برمجيًا
- شاشة ملف شخصي للأسئلة الـ21، مقسمة إلى مجموعات مع حفظ تلقائي ومؤشر تقدم.
- غرفة ومؤشرات اتصال واستعداد وشرط واضح لبدء المباراة.
- ساحة لعب مخصصة للفصول الخمسة، مع لوحة نقاط ومؤقت.
- كشف تدريجي للرسائل والتلميحات والنتائج.
- عودة إلى المهمة الحالية بعد إعادة التحميل أو استعادة الاتصال عبر API الخادم.
- تصميم RTL متجاوب وأزرار مناسبة للمس، وعميل JavaScript بصياغة ES5.
- اختبارات عقد الواجهة ضمن مجموعة الاختبارات الآلية.

**بوابة الخروج البرمجية:** 76 اختبارًا آليًا ناجحًا وفحص صياغة JavaScript. اختبار العرض الفعلي وعدم التجاوز الأفقي على الأجهزة المستهدفة يبقى ضمن المرحلة الخامسة.

## 5. الاختبارات والإطلاق العائلي — المرحلة الحالية
- اختبارات وحدة وHTTP وتكامل وأمان.
- 3 و4 لاعبين، تحديث، انقطاع، استعادة، انتهاء وقت.
- مراجعة المحتوى لغويًا وعائليًا.
- اختبار Android وiPhone 4S الفعلي.
- إصلاح الأعطال ثم تجميد الميزات وإطلاق النسخة العائلية التجريبية.

**بوابة الخروج:** لا أخطاء حرجة ولا تسرب للإجابات، ومباراة كاملة تعمل على الأجهزة المستهدفة.
